# Changelog

## 2.2.0 - 2026-11-24

- Fix: the English text never showed. The `$pt` parameter of the translation helper hid the
  global `$PT` flag (PowerShell names are case-insensitive), so Portuguese always won.
- `-Renomear <account> -Para <new name>` and `-Idioma pt|en` (or `CLAUDE_CONTAS_IDIOMA`).
- `PROMPT.md` now works with any AI: Prompt A for AIs that run commands (Claude Code, Codex,
  Cursor, Gemini CLI, Copilot agent) and Prompt B for chat-only AIs, which build one command
  for the user to paste.
- README rewritten: what Claude Contas is, everything it does, four ways to install, menu and
  command reference, and what was tested.
- Installer closing message mentions the main account's shortcut.
- Tested: Google sign-in link fired by Windows is caught and handed to the right account;
  self-update from an old version; tray notification; one-line installer end to end; install
  from a downloaded ZIP; menu in both languages; the /claude-contas skill in a Claude Code session.

## 2.1.2 - 2026-11-24

- Claude's own console output (Node `MaxListenersExceededWarning`, Electron deprecation
  notices) no longer floods the menu window: it goes to `%LOCALAPPDATA%\ClaudeContas\saida`,
  cleaned up automatically. Those messages come from Claude Desktop itself and are harmless.
- Verified: after the 45 s wait, a sign-in survives a forced close (Task Manager) and the
  account reopens signed in.

## 2.1.1 - 2026-11-24

- Sign-in helper waits 45 s after the sign-in so Claude writes the session cookie to disk.
  Chromium persists cookies about every 30 s; force-closing Claude (Task Manager) right after
  signing in lost the session and the account asked to sign in again on the next launch.
- Diagnostics recognises that case (`signed_in_at_last_exit: true` with no sign-in cookie at
  start) and explains it.

## 2.1.0 - 2026-11-24

- Scheduled automatic update (`-Agendar "12:00,18:30"`, menu → H): runs hidden at Windows
  sign-in and at the chosen times, catches up after the PC was off, updates the tool,
  rebuilds missing shortcuts and runs the self-test whenever Claude changes version.
  Tray notification only when something matters. No admin needed.
- Shortcut for the main account too (**Claude - Principal**), renameable.
- Two icon styles: Claude logo with colored badge (built locally) or the project's own
  numbered icons (`icons/conta-1..9.ico`, generated by `tools/gerar-icones.ps1`).
- Accounts are numbered 2..9 with a fixed color each; menu shows them by number.
- Install without questions for automation (`-Instalar -Sim -Contas ... -Icones ... -Agendar ...
  -ComSkill -SemEntrar`) and `PROMPT.md`, a prompt that makes Claude Code do the whole install.
- Guided installer asks: main account name, number and names of extra accounts, icon style,
  scheduler and times, Claude Code skill, sign-in.
- Rename accounts (menu → M), install the skill from the menu (K).
- Self-test closes the test instance as soon as the app logs the chosen folder, before its
  window shows up.
- Tested with the main account plus three extra accounts open at the same time.

## 2.0.0 - 2026-11-24

Rewrite after the method stopped working with the Claude Desktop update of 2026-10-20.

What was going on:

- The `.bat` pointed at `C:\Program Files\WindowsApps\Claude_<version>_x64__...\app\claude.exe`.
  Every app update removes that folder, so the shortcut died with each update.
- Signing in the second account with Google or an email link could not work while the
  main Claude was open: the `claude://` link that brings the session back is always
  delivered to the main instance. Google sign-in codes are then dropped; a magic link
  could even sign the main window into the second account.

What changed:

- One-line installer (`irm .../install.ps1 | iex`), no paths to copy, no files to edit.
- Starts Claude through the `claude-desktop.exe` alias the MSIX package registers, which
  does not change between versions. Falls back to the package folder or the legacy install.
- `-Entrar`: guided sign-in that routes the `claude://` link to the right account.
- `-Testar`: live self-test with a throwaway profile; `-Diagnostico`: health report
  (signed in or not, same account twice, old v1 shortcuts).
- Any number of accounts, each with a Desktop and Start menu shortcut and its own icon badge.
- Daily auto-update from GitHub (can be turned off in `contas.json`).
- Claude Code skill (`/claude-contas`) and `tools/investigar.ps1` to analyse a new app
  version when something breaks.
- Reuses the v1 `Claude-Work` folder.
